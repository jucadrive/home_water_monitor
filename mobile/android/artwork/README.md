# 뽀싹 앱 아이콘

`ppossak-icon-source.png`는 사용자가 2026-10-26에 제공하고 앱 아이콘으로 지정한 원본이다.
다른 출처나 별도 라이선스를 임의로 주장하지 않는다.

최소 Android 버전이 8이므로 density-independent adaptive icon을 사용한다.
108dp 전경 중앙의 72dp 영역에 원본 비율을 유지한 전체 이미지를 배치했다.
원형·둥근 사각형 마스크에서도 캐릭터와 새싹을 보존하기 위한 여백이며,
실기기 런처 검수 결과는 docs/HANDOFF.md와 해당 작업 명세를 따른다.
시스템 테마 아이콘 모드에서는 새싹·몸체 윤곽의 단색 벡터를 사용한다.
